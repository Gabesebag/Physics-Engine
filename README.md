# Physics-Engine - think of another idea

## Gameplay 

two player share blocks and use them to shield themselves from projectiles that come from 4 direction
and gets faster after each 30 second round.  

At the start players share 1 block, but the blocks increase by 1 each round up to 4 blocks.
Additionally, players/blocks cant be on the same square that has a block/player.
